# Python Notes

This repository contains beginner-friendly Python notes and examples covering core topics such as variables, operators, conditionals, loops, strings, data structures, functions, and recursion.

## Who this is for

This project is intended for learners who are starting with Python and want simple, readable examples to understand the fundamentals.

## Topics covered

- Basic Python syntax
- Variables and data types
- Input and output
- Operators
- Conditionals
- Loops
- Strings
- Lists, tuples, sets, and dictionaries
- Functions
- Recursion

## Folder structure

- `01_Basic/` - Basics and core concepts
- `02_Operators/` - Arithmetic, comparison, assignment, logical, and bitwise operators
- `03_Conditionals/` - If, else, elif, and nested conditions
- `04_Loops/` - For loops, while loops, and loop control
- `05_Strings/` - String operations and examples
- `06_Data_Structures/` - Lists, tuples, sets, and dictionaries
- `07_Functions/` - Function definitions and usage
- `08_Recursion/` - Recursion examples and patterns

## How to run a file

```bash
python3 filename.py
```

Example:

```bash
python3 introduction.py
```

## Learning progression

The files are organized in a simple progression from basic Python concepts to more advanced ones.
